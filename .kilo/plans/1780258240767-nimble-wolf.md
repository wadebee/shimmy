# Plan for Splitting Uninstall Capability

## Goal
Split the uninstall capability out of `scripts/install-shimmy.sh` into a new script `scripts/uninstall-shimmy.sh` and remove the `--uninstall` flag from the top-level launcher `install` command.

## Steps

### 1. Create Common Library
- Create `lib/repo/shimmy-common.sh` containing:
  - Helper functions used by both install and uninstall:
    * `manifest_values`
    * `manifest_shim_list`
    * `line_list_contains`
    * `line_list_append`
    * `requested_shim_append`
    * `ensure_safe_remove_path`
    * `is_shim_listed_in_manifest`
    * `is_shim_needed_by_other_profile`
    * `profile_manifest_count`
    * `remove_empty_install_dirs`
    * `write_root_manifest_existing_profiles`
    * `startup_blocks_remove`
    * `uninstall_profile_manifest_resolve`
  - Function `resolve_install_paths` (used by both install and uninstall)

### 2. Update `scripts/install-shimmy.sh`
- Source the new common library: `. "$ROOT_DIR/lib/repo/shimmy-common.sh"`
- Remove the `--uninstall` flag from argument parsing
- Remove the `perform_uninstall_profile` function and all helper functions moved to the common library
- Remove the uninstall branch in the main function (`elif [ "$UNINSTALL" -eq 1 ]; then`)

### 3. Create `scripts/uninstall-shimmy.sh`
- Shebang: `#!/bin/sh` with `set -eu`
- Setup variables similar to install script (SCRIPT_DIR, ROOT_DIR, etc.)
- Source required helpers:
  * `. "$CATALOG_HELPER_FILE"`
  * `. "$PROFILE_HELPER_FILE"`
  * `. "$ROOT_DIR/lib/repo/shimmy-common.sh"`
- Implement argument parsing for `--install-dir` and `--profile` only
- Call `resolve_install_paths` to set up variables
- Implement uninstall profile logic (moved from `perform_uninstall_profile` in install script)
- Make script executable

### 4. Update Top-Level Launcher `shimmy`
- In `main` function:
  * Change `uninstall` case to: `run_repo_script "$ROOT_DIR/scripts/uninstall-shimmy.sh" "$@"`
  * In `install` case, remove `--uninstall` from usage text (since flag removed from install script)
- Update usage text for `install` command to remove `--uninstall` option

### 5. Verification
- Ensure `shimmy uninstall` works correctly
- Ensure `shimmy install` no longer accepts `--uninstall` flag
- Ensure installation and other functionalities remain unaffected
